ns.col2.bar event filter – Something else¶

Note

This EDA event filter plugin is part of the ns.col2 collection (version 0.0.1).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install ns.col2.

To use it in a playbook, specify: ns.col2.bar.
